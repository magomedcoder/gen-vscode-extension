# Команды

В палитре команд отображаются как **Gen: ...** (категория `Gen`).

| Команда | Сочетание (Win/Linux) | macOS |
| --- | --- | --- |
| Открыть чат | `Ctrl+Alt+G` | `Cmd+Alt+G` |
| Прокомментировать выделение | `Ctrl+Alt+/` | `Cmd+Alt+/` |

Сочетания можно изменить в **Файл -> Настройки -> Сочетания клавиш** (поиск по `Gen`).

Настройки открываются кнопкой ⚙ в шапке чата (отдельной команды и сочетания нет).

- **Gen: Прокомментировать выделение** - комментарии к выделенному коду (только при выделении в редакторе)
- **Gen: Прокомментировать файл** - комментарии ко всему открытому файлу (контекстное меню редактора)

    ```
    Синтаксис комментариев зависит от языка файла:

    - `//` `/* */` - JS, TS, Java, Go, Rust, C#, CSS
    - `#` - Python, Ruby, Shell, YAML
    - `<!-- -->` - HTML, XML, Vue
    - `--` `/* */` - SQL
    - `--` `--[[ ]]` - Lua
    - `//` `#` `/* */` - PHP

    Неизвестный язык обрабатывается как ts-style (`//` / `/* */`)
    ```
