# Gen vscode extension

## Команды

**Gen: Прокомментировать выделение** - комментарии к выделенному коду

**Gen: Прокомментировать текущую функцию** - комментарии к функции/методу вокруг курсора

**Gen: Открыть чат** - панель чата

**Gen: Открыть настройки** - экран настроек Gen

---

## Чат

- **Ask** - только текстовые ответы (выделение в редакторе уходит в контекст)
- **Agent** - tool-calling: чтение/правка файлов, навигация, git status, диагностики, запуск тестов и команд

Уровень доступа агента:

- **Чтение** - только чтение и навигация
- **Спросить** - запись и удаление с подтверждением
- **Без спроса** - без диалогов (действия пишутся в Output `Gen Agent`)

Пути только внутри workspace. Запреты файлов и маскировка секретов задаются в настройках (по умолчанию пусто).

После правок можно **Восстановить снимок** (файлы как до хода агента).

Несколько файлов: агент вызывает `propose_plan`, вы подтверждаете шаги, затем идут правки. Один файл - без плана.

Список инструментов: [docs/tools.md](docs/tools.md).

## Языки

Синтаксис комментариев зависит от языка файла:

- `//` `/* */` - JS, TS, Java, Go, Rust, C#, CSS
- `#` - Python, Ruby, Shell, YAML
- `<!-- -->` - HTML, XML, Vue
- `--` `/* */` - SQL
- `--` `--[[ ]]` - Lua
- `//` `#` `/* */` - PHP

Неизвестный язык обрабатывается как ts-style (`//` / `/* */`)
